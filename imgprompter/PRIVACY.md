# 隐私说明

> 生效日期：2026-06-04

## 数据范围

本扩展不运营远程服务，不主动收集用户个人信息。运行过程中只会接触以下本地或用户主动提供的数据：

- 网页图片或截图兜底得到的图片数据
- 用户填写的 API 地址、API Key、模型名称
- AI 返回的提示词结果和生图结果
- 本地历史记录

## 本地存储

以下数据保存在浏览器本地 `chrome.storage.local`：

- 识图配置
- 生图配置
- 历史记录（最近 20 条）

扩展不会把这些数据上传到作者服务器。

## 第三方发送

当你主动执行识图或生图时：

- 图片、提示词和相关请求参数会发送到你自己配置的 AI 平台
- API Key 仅用于向你配置的目标平台发起认证请求
- 是否支持某个模型，取决于你的 API 权限、地区和套餐

请自行阅读并接受你所配置平台的隐私政策和数据处理规则。

## 不会做的事

- 不上传 API Key 到作者服务器
- 不上传历史记录到作者服务器
- 不收集浏览记录
- 不分析与当前操作无关的页面内容

## 用户可控项

- 可随时修改或清除识图配置
- 可随时修改或清除生图配置
- 可随时清空历史记录
- 卸载扩展后，本地存储数据由浏览器一并清除

## 联系与更新

隐私说明若有更新，应在项目仓库中同步说明。
