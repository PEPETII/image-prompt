# Edge 扩展商店发布说明

## 扩展名称

看图写提示词

## 简短描述（132 字符以内）

右键图片，AI 反推生图提示词。支持中英双语、JSON 结构化、风格快捷切换与二次修改。

## 详细描述

ImgPrompter 是一款轻量浏览器扩展，让你在任意网页图片上右键，即可调用 AI 视觉模型，自动生成可用于 AI 绘图的结构化提示词。

**核心功能：**
- 右键图片一键生成 AI 绘图提示词
- 支持中文 / 英文 / 中英双语输出
- JSON 结构化描述（主体、场景、光线、构图、风格等 13 维度）
- Midjourney / Stable Diffusion 格式输出
- 提示词二次修改——输入修改要求，AI 整体重写
- 6 种风格快捷按钮（写实、动漫、电影感、产品摄影、赛博朋克、3D 图标）
- 历史记录（最近 20 条，可复制、可清空）
- API 地址、密钥、模型完全自定义

**使用方式：**
1. 点击浏览器工具栏图标，在设置页填写你的 AI API 地址、密钥和模型名称
2. 在任意网页图片上右键，选择「生成 AI 图片提示词」
3. 等待 AI 分析完成，在弹出的结果面板中查看、切换格式、复制或二次修改

**隐私说明：**
- API Key 仅保存在浏览器本地，不会发送到扩展作者的服务器；仅在调用你自行配置的 AI API 时作为认证信息发送
- 图片数据仅发送到你自行配置的 AI API 服务
- 扩展本身不运营任何服务器，不收集任何用户数据

## 权限说明（商店提交时必填）

| 权限 | 用途说明（提交时填写） |
|------|----------------------|
| `activeTab` | 获取当前标签页信息，用于向当前页面注入结果面板脚本 |
| `contextMenus` | 在图片右键菜单中添加「生成 AI 图片提示词」入口 |
| `scripting` | 向当前页面注入内容脚本以显示分析结果面板 |
| `storage` | 将用户 API 配置和分析历史记录保存在浏览器本地（chrome.storage.local） |
| `tabs` | 在图片 URL 无法下载时，截取当前标签页中该图片可见区域作为兜底（不用于浏览历史或其它用途） |
| `<all_urls>` (host_permissions) | 在任意网页上使用右键菜单读取图片数据、注入结果面板；不会访问或修改页面其他内容 |

## 隐私摘要（商店提交时必填）

- 本扩展不收集、不存储、不传输任何用户个人身份信息
- API Key 仅保存在浏览器 chrome.storage.local 中，不会发送到扩展作者的服务器；仅在调用用户自行配置的 AI API 时作为认证信息发送
- 图片数据仅在用户主动右键触发分析时，发送到用户自行配置的 AI API 服务，不会发送到其他任何服务
- 扩展本身不运营任何服务器，不包含任何第三方追踪或分析代码
- 历史记录保存在浏览器本地，最多保留 20 条，用户可随时清空
