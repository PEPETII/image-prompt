# 上传前手动测试清单

在提交到 Edge 扩展商店之前，按以下清单逐项测试。每项必须通过才能提交。

## 一、扩展加载

| # | 测试项 | 操作 | 预期结果 | 通过 |
|---|--------|------|---------|------|
| 1.1 | Edge 加载扩展 | 打开 `edge://extensions`，开启开发者模式，点击「加载已解压的扩展程序」，选择 `imgprompter` 文件夹 | 扩展成功加载，无报错，图标出现在工具栏 | ☐ |
| 1.2 | 扩展重新加载 | 在 `edge://extensions` 点击刷新按钮 | 扩展重新加载成功，无报错 | ☐ |
| 1.3 | Service Worker 正常 | 点击「背景页」/「Service Worker」链接 | 控制台无红色报错，`importScripts` 正常执行 | ☐ |

## 二、设置页
